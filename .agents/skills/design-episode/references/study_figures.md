# Conceptual study figures

Use this reference for concept figures and graphical study explanations, not
for plotting measured results. Work only with the requested episode's permitted
design material and explicitly allowed style references.

## Scientific content and visual language

Read the current question and intended comparison before editing the picture.
Inspect accepted figures from other episodes as style references when access
is permitted; do not infer their scientific results or copy their claims.
Keep what makes them readable rather than inventing a new visual style each time.

Show the actual relationship: available observations, the representations or
components being compared, and the decision the experiment will inform. Use
only panels and arrows that help explain that relationship. Neither the
administrative workflow nor a wall of validity caveats is the main figure.

Use concise English labels, a clear reading order, restrained color, consistent
type hierarchy and enough space. Avoid decorative brains, excessive icons,
tiny text, saturated gradients and boxes for every implementation detail.
Explain necessary limitations in a short caption alongside the claim.

## Generate and inspect

For this repository's new conceptual raster figures, use image-gen with the
available imagegen skill and permitted style references. Follow the skill's
tool and privacy instructions; do not upload restricted data. If the tool is
unavailable, report the gap rather than claiming that a fallback was generated
by image-gen. Preserve an explicitly requested existing vector/code format.

Inspect the generated image itself at full size and normal reading size. Check
labels, spelling, arrows, component meaning, legibility and agreement with the
current design. Revise specific defects; generation success is not figure
approval. A request to inspect an existing figure does not itself authorize
replacing it.

Use the established episode filename/location where possible and update the
relevant document embeds and captions. Label the picture as a study schematic;
do not show fabricated favorable curves, anatomical evidence or measured values.
Measured result figures belong to the execution/analysis workflow and must be
rendered from their actual permitted data. Do not add figure quotas or an
artifact/provenance report solely to accompany an image.
