# Research landscape

The campaign starts with a few broad areas where the available data and the
scientific uncertainty overlap. This file is a reading map, not the canonical
Brain Researcher Landscape.

## Current themes

### Analysis flexibility and inferential stability

The NARPS episodes ask which parts of a result change when confound handling,
subject exclusion, smoothing, scaling, masking, and sampling decisions change.
The interesting target is not another multiverse ranking. It is a mechanistic
account of why a conclusion changes and whether that change survives a matched
null or independent analysis path.

### Reliable task-fMRI measurements

The n-back proposal asks whether a whole-brain high-load versus low-load
response can be made reliable without becoming less valid. Reliability alone
is insufficient: a stable signature may still measure motion, stimulus
category, site, or general difficulty.

### Cross-dataset transport and boundary conditions

When a measurement transfers, we want to know which components remain stable
across session, task, population, scanner, and site. When it fails, the failure
should localize a boundary rather than trigger unrestricted retuning on the
target cohort.

### Meta-science of autonomous analysis

Across 100+ episodes, we want to measure whether bounded agents produce useful
new tests while preserving failed paths and confirmation firewalls, or whether
they merely search analysis choices until something looks publishable.

## How this file changes

Add or revise a theme when several episodes expose the same uncertainty, or
when a confirmed result genuinely changes what should be tested next. Keep
episode-specific numbers and claims in the episode itself.
