# Design-example inputs

No scientific inputs are provisioned by this draft.

If the design is ever instantiated, its input surface should expose only:

- `development/`: content-addressed EP01/EP02 lineage plus immutable NARPS
  `ds001734` source references;
- `audit_manifest/`: identity, schema, counts, and hashes for `ds000005`, with
  no candidate-discriminating neural arrays; and
- synthetic fixtures for operator, mask, metric, and audit-runner tests.

The real `ds000005` audit payload must remain permission-separated until the
configuration-lock hash exists. Inputs are read-only during an authorized run.
