# Outputs

The tracked output surface contains only durable specifications, reusable
code/tests, and the seven required projections. It contains no scientific
result.

- `firewall/`: the current lean permission-separation contract and
  provisioning explanation. The old external-receipt filename is retained as
  a deprecation marker only.
- `code/`: portable Phase-0 inventory, role materializer, generic calibration,
  provisional endpoint-shaped calibration, legacy firewall verifier, and
  `$SCRATCH`-scoped Slurm launchers. Legacy hash/receipt helpers are not
  readiness gates.
- `tests/`: pure-function and clean-clone tests; packet tests skip unless an
  ignored runtime packet is present. Assertions specific to retired
  hash/receipt formats are implementation history, not current readiness
  checks.
- The seven top-level Markdown files: local projections, never canonical
  evidence or authority.

Generated calibration tables, inventories, role packs, and pre-outcome
assessments belong in scratch or another runtime store and must not be
committed.
