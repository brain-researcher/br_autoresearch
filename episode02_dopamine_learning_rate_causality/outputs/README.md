# Outputs

The tracked output surface contains only durable specifications, reusable
code/tests, and the seven required projections. It contains no scientific
result.

- `firewall/`: stable permission-separation contract and explanation.
- `code/`: reusable endpoint-faithful calibration engine and Slurm launcher.
- `tests/`: tests for the calibration engine and search policy.
- The seven top-level Markdown files: local projections, never canonical
  evidence or authority.

Generated calibration tables, inventories, role packs, receipts, signatures,
and checksum sidecars belong in scratch or another runtime store and must not
be committed.
