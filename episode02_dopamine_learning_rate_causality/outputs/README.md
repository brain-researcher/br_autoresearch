# Outputs

The tracked output surface contains only durable specifications, reusable
code/tests, and the seven required projections. It contains no scientific
result.

- `firewall/`: incomplete permission-separation contract template, unsigned
  external-receipt template, and provisioning explanation.
- `code/`: portable Phase-0 inventory, role materializer, generic calibration,
  provisional endpoint-shaped calibration, firewall verifier, and `$SCRATCH`-
  scoped Slurm launchers.
- `tests/`: pure-function and clean-clone tests; packet tests skip unless an
  ignored runtime packet is present.
- The seven top-level Markdown files: local projections, never canonical
  evidence or authority.

Generated calibration tables, inventories, role packs, receipts, signatures,
prelaunch assessments, and checksum sidecars belong in scratch or another
runtime store and must not be committed.
