# Memory

The design revision produced no observation about neural data. Its main
scientific commitments are:

- predicting an average trajectory is not enough;
- the correct trial's LFP must beat a wrong LFP trial for the same target;
- the effect must not be driven by one session, one animal, or only
  high-frequency spike-rich features; and
- a positive decoder result motivates, but does not establish, a shared
  LFP/spike population explanation.

No belief about the outcome should be updated until the planned comparisons
have been run.
