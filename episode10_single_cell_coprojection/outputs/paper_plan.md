## The paper's central question

Among neurons from one source that all arborize in A, does positively recorded
co-target context predict a different terminal layout inside A after soma,
layer, and flexible continuous geometry are controlled? Can full axon trees
explain that conditional shift, and does the prediction reproduce in previously
unopened biological groups?

The intended discovery is not a new list of target combinations or new
projection-defined cell classes. It is an explanation of a named pathway that
a regional mean suppresses. For example, a fixed B-positive context predicts a
shift along one biologically meaningful coordinate in A compared with a fixed
C-positive context, even on common source-space support. The same direction
must be frozen before held-out testing; it cannot be selected from final
profiles.

Both contexts are positive observations. B-positive does not mean C-negative.
Neurons with A+B+C recorded can belong to both summaries; retain their identity,
report the overlap, and use covariance-aware group-level inference.

The inference from these sources is that the new paper must be **pathway- and
explanation-specific**. They do not demonstrate that EP10's unchosen candidate
is novel. Before evaluation, write a concise candidate rationale: the named
source/A/contexts, closest existing answer, unresolved explanation, fixed
prediction, and interpretation changed by either outcome. If nothing distinct
remains, present a replication/extension or stop; do not rescue novelty with
a new atlas label.

## Primary estimand and evidence

The measurement is the neuron-normalized qualifying terminal-arbor profile
q_iA in frozen within-target coordinates. Keep total arbor length in A separate.

The proposed primary endpoint is a signed, group-first B-positive minus
C-positive anatomical profile-summary contrast, standardized to the same
measured soma/layer/quality distribution on common support. Choose one
anatomically justified coordinate/summary, direction, useful margin,
uncertainty, and multiplicity prospectively. Context-blinded technical
repeatability may choose among prespecified profile implementations; the
observed context separation cannot.

This is a contrast of recorded observations, not a causal intervention and not
a comparison of mutually exclusive projection types. Group-level resampling
must retain A+B+C overlap and within-group cell dependence. Independent labels
must not be learned from these axons.

| Evidence | Role in the paper |
| --- | --- |
| Frozen within-A context contrast in unseen groups | Scientific primary: does the named conditional terminal shift reproduce? |
| Profile prediction from flexible source-space reference versus reference plus positive context | Supporting discrimination: is measured continuous source geometry sufficient? |
| Entry-route, branch, collateral, and boundary characterization | Explains implementation or identifies a competing anatomical account; not independent validation. |
| Pooled neuron-normalized A profile versus context profiles, with frozen discrepancy/margin | Quantifies exactly what the specified averaging operation omits. |
| Existing target-pattern score and its search-calibration procedure | Exploratory target-observation evidence only; does not validate or calibrate the terminal primary. |

A profile difference with no useful predictive increment or robustness remains
a limited descriptive association. A predictive increment with no frozen,
meaningful anatomical contrast is a methods result, not the intended pathway
paper. The terminal-coordinate useful margin must be defined separately from
any target-pattern search threshold.

## Study sequence

### 1. Name a feasible, unresolved pathway

Use biological rationale, permitted development target information, and
candidate-specific prior work to choose one source/shared A/positive contexts.
Do not choose targets by scanning within-A profile separation or final anatomy.
Assess context overlap and group/position support only in development roles.

Gao MOp is a documented candidate resource; the follow-up source remains to be
chosen. That choice does not reassign any existing frozen execution.
Source-module labels are used only if a fixed source-space mapping is available
without the evaluated neuron's axon. A flexible continuous soma/layer model is
the mandatory rival; module labels cannot replace it or guarantee its adequacy.

### 2. Freeze a reliable anatomical measurement

Establish atlas registration, target-intrinsic coordinates, normalization,
profile repeatability, clipping/unknown content, and amount sensitivity with
context labels blinded. Freeze the predicted anatomical direction and one
meaningful profile-scale margin from the candidate rationale, not from final
separation.

Source/quality adjustment, other positively recorded co-target overlap,
group weighting, the profile estimator, pooled-map estimator, and uncertainty
are fixed together. Do not analyze B-negative or C-negative biological classes.
If positive-context and source-space common support are insufficient, the
proposed contrast is not identified for that population.

### 3. Distinguish source geometry from contextual implementation

Fit the development-frozen continuous reference and a capacity-controlled
context addition for within-A profiles. Both predict the same cells in the
same support domain. Target count is recorded-positive K_i_obs, not true
biological target count.

Report reference calibration, effect heterogeneity, quality dependence, and
leave-one-group influence. If independent layer/driver/molecular labels are
absent or confounded, population composition remains unresolved. No axon-
derived Projection class or profile cluster can rule it out.

### 4. Test the terminal primary in held-out groups

Freeze a separate biological evaluation/access contract before opening the
existing final groups. Final-group profiles cannot choose support, metric,
direction, targets, weights, or examples. A future support shortfall gives an
inconclusive endpoint, not a replacement candidate.

The anatomical endpoint needs its own group-level inference, dependence-aware
null or uncertainty model, and selection/multiplicity treatment. The 99
target-pattern controller nulls cannot be repurposed as its significance test.

### 5. Explain the branch arrangement and pooling consequence

Characterize entry into A and terminal-tree organization with matched structural
references. Declare entry route as an alternative explanation or potential
mediator; do not automatically adjust it away. Report the source-adjusted
contrast first and the separately declared route analysis second. Neither
establishes causal mediation.

Check whether separate terminal branches or a continuous boundary-crossing
arbor creates the effect, and test amount, alignment, clipping, and boundary
sensitivities. Show group distributions and fixed-rule examples.
A raw amount-weighted regional map is not the group-first average of
neuron-normalized q_iA. The pooling discrepancy names its exact averaging
operation, null, margin, and uncertainty.

### 6. Transfer only when the estimand and samples transfer

An independent reconstruction workflow may test the frozen positive-context
profile prediction only after source-space, target coordinates, normalization,
observation quality, and biological identity are comparable. A different
paper or database is not a new sample. No comparable resource means an
explicitly internal cross-group result, not invented external validation.

## Outcomes and editorial decisions

| Future result | Manuscript route |
| --- | --- |
| Named context shift reproduces beyond measured continuous geometry, branch implementation is robust, and pooling loss is informative | Conditional pathway-implementation paper, subject to exact novelty beyond Yuan/Gao/Falasconi and verified group scope. |
| A reproduced shift is explained by measured soma/layer/module composition, with a useful upper bound on contextual residual | A narrowly scoped explanation or rigorous extension of source-space organization; not automatically a discovery paper. |
| Only profile prediction improves or only a development profile differs | Methods/descriptive result, not the intended biological claim. |
| Quality, clipping, registration, boundaries, or one specimen explain the contrast | Measurement or sample limitation; do not claim a wiring rule. |
| Power, overlap, or common support is inadequate | Unresolved. No new classes, absence claim, or post hoc primary substitution. |
| Closest prior work already answers the exact candidate | Replication/extension or stop. |

A non-significant contrast is not equivalence. A useful residual bound requires
precision and sensitivity at the predeclared profile-scale margin.
