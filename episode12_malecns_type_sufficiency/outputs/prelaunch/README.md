# EP12 prelaunch

This directory holds evidence produced before any real connectivity outcome is
opened. Its artifacts qualify the actual scientific fitter, synthetic
operating characteristics, source schema, roles, resource profile, and launch
lock. Merely creating a listed file does not pass a gate: every status must be
derived from executable checks and bound to content hashes.

The prelaunch stage may read the already exposed annotation fields and Arrow
schemas. It must not read body-statistic values, graph-weight rows, synapse
values, or neurotransmitter values. Development connectivity remains disabled
until a complete launch manifest records all required passing evidence and an
explicit scientist instruction authorizes that exposure.

`METHOD_FREEZE.md` records the five concrete choices now enforced by the
generated-data executor. `source_preflight/` contains the annotation-only role
split and schema evidence. Directories named `scientific_qualification_*`
contain executed T/U/M synthetic results; a directory is evidence only to the
extent that its own manifest says its gates passed. Developmental runs are
retained rather than rewritten as successful qualifications.
