## Question and contribution

Does reproducible within-type organization matter for a named structural
circuit inference? The outgoing T/U/M round tests bilateral reproducibility
in one male. The planned circuit round asks whether a type average misstates
which input and output partners meet on the same cells, and whether retaining
organization improves held-out structural prediction.

The identity separating the mean of input–output outer products from the
outer product of their means is a covariance identity, not new mathematics.
The possible biological contribution is a consequential, previously untested
named association or a useful bound on what a particular average loses.
This pair-mass description is not causal signal flow or a behavioral result.

## A literature-motivated example, not an adopted case

DNg02 makes the structural question concrete: beyond its known population
control of flight, do individual cells preserve visual-input/flight-premotor-
output associations that a type average obscures? Population coding does
**not** imply interchangeable wiring; these can coexist.

This is an optional illustration, not a selected endpoint or fixed shortlist.
Historical DNg02 is not guaranteed to be one current provider type:
[FlyBase's annotation](https://flybase.org/cgi-bin/cvreport.pl?childdepth=2&cvterm=FBbt%3A00047594&rel=is_a)
lists finer DNut007–DNut010 names. Existing development-role eligibility,
bilateral support, current subtype distinctions and prior circuit analyses
have not been established here. Do not pool finer labels to manufacture
within-type replication. If its association is already known, it is a
benchmark. The actual new case must come from the permitted scientific stage,
not this illustrative paragraph.
