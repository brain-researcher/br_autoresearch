# Working memory

The key explanatory object is the alignment between voxelwise model advantage
and a calibration-defined operator map. Beta stages can change the voxelwise
advantage; support changes membership; ceiling normalization changes positive
weights only. The audit uses new concepts in the same four participants and
does not refit the readout.

For support and ceiling, exact reaggregation is a development-only
attribution. The audit test is a distinct forecast frozen from development
advantages; audit advantages cannot construct that forecast. All maps are
defined within participant and ROI before equal-participant aggregation.
