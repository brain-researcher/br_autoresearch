# Working memory

October 2 superseding scope: which visual-model advantages survive changes in
the measured cortex? Claim-specific eligibility replaces the single-training-
property rule. Fixed-weight support/ceiling forecasts equal the development
edge and test new-concept repeatability, not an independent mechanism. See
[scope review (consolidated)](paper_plan.md). Named models remain starting
contrasts; no scores or execution occurred.

Independent review also established that spatial-bin intercepts make the beta
aggregate forecast equal its fitted development target mean. Reliability-gain
incremental prediction is not established by that aggregate test or by the
registered descriptive high/low contrast.

Paper focus, 2026-09-30: DINO versus supervised ResNet-50; anatomical left/right
fusiform, not functional FFA; pure D-stage `A_N → R_N` membership. SwAV supplies
two dependent supporting nominations, not independent replications. These
choices are unqualified and do not reduce the operative coverage or budget.

The key explanatory object is the alignment between voxelwise model advantage
and a calibration-defined operator map. Beta stages can change the voxelwise
advantage; support changes membership; ceiling normalization changes positive
weights only. The audit uses new concepts in the same four participants and
does not refit the readout.

For support and ceiling, exact reaggregation is a development-only
attribution. The audit test is a distinct forecast frozen from development
advantages; audit advantages cannot construct that forecast. All maps are
defined within participant and ROI before equal-participant aggregation.

Training recipes differ; no causal objective or clean-exposure claim follows.
For the headline edge, freeze `sum((w_R-w_A)*d_dev)` and compare it with
`sum((w_R-w_A)*d_audit)`, never feeding audit advantages into the forecast.
The algebra alone is not a novel result; a precise, useful empirical forecast
or conditional relation must add the scientific evidence.
